Pangolin CLI

                        

                            
                            
                            
Release of fosrl/cli to download, or latest. Downloads are checked against the SHA-256 digest GitHub publishes.

                        

                        

                            
                            
                            
Use an existing pangolin executable instead of downloading one. Required when using sudo.

                        

                        

                            
                            
The CLI must run as root to create the WireGuard interface. Only for bare-metal installs where Jellyfin runs as its own user and a sudoers rule is set up (see the README). In Docker, leave this off and run Jellyfin as root (PUID=0 and PGID=0 on linuxserver.io).

                        

                    


                    

                        
DNS

                        

                            
                            
Lets the client take over DNS so private resource aliases (e.g. ldap.home.internal) resolve. Needed for LDAPS if the certificate is issued for the alias.

                        

                        

                            
                            
                            
Comma-separated patterns sent to Pangolin DNS. Other lookups go straight to the system resolver. Empty sends everything through Pangolin DNS.

                        

                        

                            
                            
                            
Comma-separated servers for names that are not Pangolin resources. Empty keeps the client default.

                        

                        

                            
                            
Only when the upstream DNS server is itself a Pangolin resource.

                        

                    


                    

                        
Advanced

                        

                            
                            
If a CIDR resource overlaps this server's LAN, keep LAN traffic local so clients can still reach Jellyfin.

                        

                        

                            
                            
Only allow direct (hole-punched) connections to sites.
